# MathMongo v0.14.0-teaching-rc1

## Identidad

MathMongo es el producto. `MathV0` es la base histórica física recomendada
para instalaciones docentes existentes. Esta release no renombra, migra,
fusiona ni modifica esa base; el nombre de la base sigue siendo configurable.

## Entorno docente verificado

La validación se realizó en Ubuntu 22.04.5 LTS con:

- Python 3.10.12
- Streamlit 1.59.2
- PyMongo 4.17.0
- MongoDB 7.0.35, FCV 7.0
- Pydantic 2.13.4
- Pillow 12.3.0

Las versiones de aplicación están fijadas para este entorno en
`constraints/teaching-2026.txt`.

## Cambios incluidos

- Configuración explícita de conexión y presentación inequívoca de la base
  activa.
- Runtime local con identificación segura de procesos, diagnóstico y comandos
  Make compartidos.
- Tema docente, navegación y formularios de Sources estabilizados.
- Estilos Cornell/CPI clásicos e híbridos continuos ya disponibles en el
  editor.
- Backup/restauración verificable con manifiesto, estructura MongoDB y media
  portable.
- Doctor y diagnósticos de catálogo de sólo lectura.
- CLI ligero al importar, con los comandos académicos de sólo lectura que se
  muestran en `mathmongo --help`.

## Operación local

Los comandos disponibles del Makefile son:

```bash
make start    # comprueba runtime y MongoDB; no inicia Streamlit
make status   # diagnóstico de runtime y MongoDB
make run      # inicia el runtime local verificado
make stop     # detiene únicamente un runtime identificado como propio
make restart  # reinicia únicamente un runtime identificado como propio
```

La configuración seleccionada puede inspeccionarse sin conexión mediante:

```bash
mathdbmongo/bin/python -m mathmongo config
```

## Backup y recuperación

Antes de actualizar o cambiar de equipo, conserva el backup de MongoDB y el
árbol XDG de MathMongo. Crea y verifica un backup, y restaura siempre primero
en una base nueva:

```bash
mathdbmongo/bin/python -m mathmongo.backup backup --output-dir /ruta/segura/backups
mathdbmongo/bin/python -m mathmongo.backup verify-backup /ruta/segura/backups/archivo.manifest.json
mathdbmongo/bin/python -m mathmongo.backup restore-to-new-database \
  /ruta/segura/backups/archivo.manifest.json \
  --target-database MathV0_teaching_restore
```

No uses `Clear All Data`, `--drop` ni una restauración sobre `MathV0` como
parte de este flujo.

## Limitaciones conocidas

- Audio no está implementado en MathMongo; Waveform Lab continúa siendo un
  proyecto separado.
- El CLI académico no declara paridad completa de escritura con la interfaz;
  sólo están soportados los subcomandos que aparecen en su ayuda.
- No existe importador de proyectos Cornell/CPI editables en esta RC.

## Política de actualizaciones

No actualices MongoDB, Streamlit ni PyMongo antes de realizar, en este orden:

1. backup y restauración aislada en una base nueva;
2. suite de pruebas;
3. instalación limpia con `constraints/teaching-2026.txt`;
4. smoke de Streamlit en un puerto y XDG temporales.
