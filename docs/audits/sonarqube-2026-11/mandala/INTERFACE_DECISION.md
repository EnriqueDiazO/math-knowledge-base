# Interfaz elegida y transición

Se conserva el contenedor Streamlit y se consolida la experiencia de estudio en
su componente web CCv2 TypeScript. La sustitución completa está autorizada; no
resulta necesaria para este recorrido. El editor Tiptap/MathLive, el lector HTML,
Canvas, la cámara y los borradores pertenecen al cliente y no envían pulsaciones
ni movimientos a Python. Python recibe únicamente intenciones explícitas y
devuelve datos confirmados por los servicios canónicos.

Evidencia: el recorrido real de Chrome recupera un documento con fórmula
incompleta después de recargar, la completa y guarda una única entidad. Los
diálogos nativos aprovechan la ventana y el mapa expandido supera el 85 % de la
altura en ambos escenarios de escritorio. La regresión de MathLive se debió al
saneado de su atributo contenteditable y a la selección diferida entre fórmulas;
no demuestra una imposibilidad de CCv2. Se conservan los recursos locales y no se
añade otra biblioteca documental ni otra capa de autenticación/API.

La separación debe mantenerse al ampliar la habitación: adaptador de transporte,
estado local, documentos, escena, vistas y servicios. Una navegación completa
independiente requeriría reproducir de forma verificable biblioteca, anotaciones,
exportación, mantenimiento y selección de conexión; no ofrece una mejora
demostrada para cerrar este recorrido. El lector PDF existente continúa siendo el
consumidor canónico de documentos, posición, subrayados y referencias.

La matriz de funciones y retiradas se actualizará con cada lote verificado. Los
formularios anteriores sólo se retirarán cuando se hayan cubierto sus herramientas
y consumidores, incluidos callbacks y accesos dinámicos. Los editores Cornell/CPI
atienden modelos de notas y exportación distintos; no se consideran duplicados
por usar también LaTeX.

Esta decisión no cierra la revisión del resto del repositorio. El inventario de
archivos grandes y los análisis Sonar se mantienen como condiciones de entrega.
